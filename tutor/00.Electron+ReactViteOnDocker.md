# Electron + React (Vite) Docker 全容器化開發環境建置指南 (上)

## 一、 核心概念與開發架構評估

### 1. 核心挑戰：Docker 容器如何運行桌面端 GUI？
* **React 部分**：屬於純網頁前端，運行在容器內並透過通訊埠（Port）對外暴露服務，建置非常容易。
* **Electron 部分**：結合了 Node.js 與 Chromium，需要呼叫作業系統的視窗介面（GUI）。在 Docker 容器中若要直接顯示視窗，必須克服「找不到螢幕（Display）」的問題。

### 2. 架構策略對比
在建置過程中，我們評估了三種不同的開發路徑：

| 評估項目 | 混合模式 | 方案 A：Dev Containers | 方案 B：網頁 VNC 模式 (最終採納) |
| :--- | :--- | :--- | :--- |
| **本地端環境要求** | 需要安裝 Node.js / npm | 完全不裝 npm，需安裝 XServer 軟體 | **完全不裝 npm，只需安裝 Docker 與瀏覽器** |
| **Electron 視窗表現** | 宿主機原生視窗 | 透過 XQuartz 轉發至 Mac 桌面 | **鎖在瀏覽器分頁內的 Linux 虛擬桌面** |
| **設定複雜度** | 簡單 (僅需處理前端代理) | 中等 (需要設定 Mac 的 XQuartz 權限) | **極簡 (利用 LinuxServer.io 的 Webtop 鏡像)** |
| **主要優勢** | 100% 原生流暢度 | 本地環境乾淨，可看見原生視窗 | **團隊環境 100% 絕對統一，開箱即用** |

## 二、 網頁 VNC 模式環境建置與底層排坑 (Ubuntu 26.04 t64 轉型)

在執行「純網頁 VNC 模式」時，底層採用了 LinuxServer.io 推出的 `webtop:ubuntu-mate` 鏡像。在安裝 Node.js 與 Electron 依賴時，我們遇到了新版作業系統核心變更的重大挑戰。

### 踩坑 1：Vite 啟動錯誤 (Port 3000 is already in use)
* **原因**：Webtop 鏡像內建的 noVNC 遠端桌面伺服器在容器內部**固定佔用了 3000 埠**。
* **解法**：將 Vite (React) 的開發伺服器埠號錯開，手動指定移至 **`5173`** 埠。

### 踩坑 2：Electron 平台執行檔衝突 (Electron failed to install correctly)
* **原因**：因為 Docker 掛載了 Mac 本機的資料夾 (`volumes`)，如果本地曾執行過 `npm install`，會殘留 macOS 版的 Electron 二進位檔，導致 Linux 容器無法驅動。
* **解法**：在容器內的 VNC 終端機清除 `node_modules`，並強制指定平台重新下載：`npm install --platform=linux`。

## 三、 最終可順利建置之環境設定檔

### 1. `Dockerfile`
負責建立一個內建 Node.js 且完全補齊 Electron 執行必備之 Linux GUI 依賴函式庫的自訂映像檔。

```dockerfile
# 基礎映像檔：使用 LinuxServer.io 官方的 Ubuntu-MATE 桌面
FROM lscr.io/linuxserver/webtop:ubuntu-mate


# 1. 自動安裝適配 Ubuntu 26.04 新系統的 Electron GUI 依賴套件（已解決 t64 套件名稱問題）
RUN apt-get update && apt-get install -y \
    libnss3 \
    libnspr4 \
    libatk1.0-0t64 \
    libatk-bridge2.0-0t64 \
    libcups2t64 \
    libdrm2 \
    libgtk-3-0t64 \
    libgbm1 \
    libasound2t64 \
    libsecret-1-0 \
    alsa-utils

#    && rm -rf /var/lib/apt/lists/*

# 2. 安裝 Node.js 20 官方 LTS 版本與 npm
RUN apt -y install curl dirmngr apt-transport-https lsb-release ca-certificates
# v20.20.2
RUN curl -sL https://deb.nodesource.com/setup_20.x | sudo -E bash -
RUN apt-get install -y nodejs
# RUN apt install npm # 除了 Node.js 之外，此命令還將安裝 NPM 以及其他依賴套件。
RUN npm install -g npm@10.8.2 


# 設定預設工作目錄（進去網頁終端機時會在這裡）
WORKDIR /config/workspace

## local visit the URI, http://localhost:6800/
```

### 2. `docker-compose.yml`
配置共享記憶體與 Chromium 必備的安全沙盒提權，確保 Electron 能在網頁桌面上順利彈出。

```yaml
version: '3.8'

services:
  webtop-dev:
    build: .               # 關鍵：告訴 Docker 使用當前目錄的 Dockerfile 來進行編譯
    # image: lscr.io/linuxserver/webtop:ubuntu-mate
    container_name: mac_electron_vnc
    security_opt:
      - seccomp:unconfined # 坑 1 解決：Electron 內建的 Chromium 沙盒需要此權限，否則視窗會打不開
    shm_size: "1gb"        # 坑 2 解決：Electron/Chromium 渲染極度消耗共享記憶體，預設 64MB 會直接崩潰
    ports:
      - 6800:3000          # 網頁虛擬桌面連線埠 (Safari/Chrome 連這裡)
      - 5173:5173          # 備用：React 開發伺服器對外埠
    volumes:
      - .:/config/workspace # 將你 Mac 的專案程式碼掛載進虛擬桌面的家目錄中
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Taipei
    restart: unless-stopped
```
