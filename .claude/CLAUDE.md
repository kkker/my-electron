# 協作規範

與 Claude 協作此專案時，請遵守以下規則：

## 回覆語言

- 所有回覆一律使用繁體中文。

## 修改流程

處理「修改類」需求（修 bug、調整功能、重構等）時，必須依序進行：

1. **說明原始機制**：異動任何檔案之前，先描述相關功能目前的運作方式（涉及哪些檔案、資料／呼叫流程、關鍵程式碼位置）。
2. **展示預計異動內容**：列出所有預計新增、修改、刪除的檔案（含多個相關檔案），並逐一展示異動內容（修改以 diff 或修改前／後對照呈現；新增檔案展示完整內容；刪除檔案說明原因）。
3. **等待確認**：等我明確確認異動內容後，才開始實際修改檔案。未經確認，不得新增、修改或刪除任何檔案。
